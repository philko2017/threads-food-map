# 脆友美食地圖

專門收錄在 Threads 經營的在地獨立美食小店指南。完全採用免費開源技術（Leaflet + OpenStreetMap），無須登入即可瀏覽地圖、尋找附近的店，並支援店家一分鐘填表上架與專屬宣傳圖卡分享。

- **線上體驗**：https://philko2017.github.io/threads-food-map/
- **發起帳號**：[@its.all.good.73](https://www.threads.net/@its.all.good.73)

---

## 目前功能

1. **美食地圖與附近定位**
   - 依 8 種美食類別（餐廳、小吃、咖啡、甜點、飲料、烘焙、伴手禮、酒吧居酒屋）、縣市與關鍵字即時篩選。
   - 支援標記群聚顯示，以及「附近的店」一鍵定位。
   - 同時支援實體店面與純宅配／網購店家。

2. **店家清單與詳細卡片**
   - 清單模式可依最新加入、縣市地區、類別排序。
   - 點擊任一店家可滑出詳細卡片，提供「去 Threads」、「去 IG」、「Google 地圖導航」、「回報資訊有誤」等功能。

3. **店家免費登錄與公開收錄規則**
   - 點擊「免費登錄我的店」即可填寫基本資訊送出。
   - 內建公開收錄規則說明，確保資訊透明與資料品質。

4. **專屬分享頁與宣傳圖卡**
   - 每家店皆有專屬分享連結（`?store=店家編號`）。
   - 內建 Canvas 宣傳圖卡產生器，可一鍵下載 PNG 圖卡、複製預寫好的 Threads 分享文或分享給 LINE 好友。

5. **公開資訊與開源改版**
   - 頁面右上角提供「版權宣告」，載明資料取之於網路、用之於網路，歡迎自由分享與改版共創。

## 專案結構

- `web/`：靜態單頁網頁（`index.html`、`styles.css`、`app.js`、`config.js`、`seed_stores.js`），可直接部署至 GitHub Pages、Cloudflare Pages 或 Vercel。
- `n8n/`：自動化收單、每日審核推播、事件與點數 API 等工作流程匯入檔與試算表欄位範本。

## 授權與使用說明

歡迎 Fork 本專案改版或架設屬於自己社群的美食地圖。若需修改或下架店家資料，歡迎透過網頁上的「回報資訊有誤」或至 Threads 聯繫 `@its.all.good.73`。
